edgeone-sync

这是一个部署在 EdgeOne Makers 上的云端同步服务：本地工具（如 iptest-web）用 token 把订阅 / 结果文件上传到云端 Blob 存储，其他人通过公开 URL 直接读取。

主页本身不提供功能，接口说明见项目 README。接口速览：

GET    /<key>                          # 公开读取，无需 token
PUT    /<key>   x-token: <WRITE_TOKEN>  # 上传 / 覆盖
DELETE /<key>   x-token: <WRITE_TOKEN>  # 删除

示例：https://<你的域名>/subs/cloudflare-ips.txt

部署后需要做的事

  1. 在 项目设置 → 环境管理 → 编辑（生产）→ 环境变量 中设置 WRITE_TOKEN，然后重新部署一次。
  2. 用 curl 验证上传与读取：curl.exe -X PUT "https://<你的域名>/subs/test.txt" -H "x-token: <WRITE_TOKEN>" --data "hello"
  3. 把 https://<你的域名> 和 WRITE_TOKEN 填入 iptest-web 的云端同步配置。

存储数据持久化在 EdgeOne Makers Blob（免费额度 1GB），首次写入时自动创建命名空间，无需在控制台绑定存储。
