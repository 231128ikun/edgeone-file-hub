edgeone-sync · 云端文件管理

部署在 EdgeOne Makers 的同步服务：上传订阅/结果文件，生成公开 URL 供外部读取。

1 写入 Token

Token 只保存在本浏览器（localStorage），管理操作（列表/上传/删除）需要它；公开读取链接不需要 token。

2 上传 / 更新文件

单次请求最大 1MB（Makers 平台限制）。上传成功后外部访问 URL = https://<你的域名>/<云端路径>。

update.bat 一键更新

    
在「已上传文件」里点击 下载 update.bat：把本地文件直接拖到 bat 上（或双击后输入路径），脚本会自动 PUT 到云端指定路径并覆盖，适合每次跑完 iptest 顺手更新订阅。

    
限制

    
单请求正文 ≤ 1MB；存储免费额度 1GB；读取默认强一致（上传后立即可读）。
